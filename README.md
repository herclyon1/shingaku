## ✕ 出願不可

- **太成学院大学** — 要求 N2 112 分以上，你 111 分差 1 分（EJU220／JPT525／J.TEST C级600 也可以替代）
- **日本工業大学** — 必须有 EJU（日语230分，还要考数学课程2）。不认 JLPT
- **平安女学院大学** — 女子大学（你指定排除）
- **園田学園大学** — 女子大学实质（2025年4月才由园田学园女子大学改制共学，在校生构成仍是女子大延续）——按你的短大·女大指定排除
- **駒沢女子大学・短期大学** — 女子大学（你指定排除）
- **大阪国際大学** — 必须有 EJU（日语200分）。不认 JLPT
- **近畿大学** — 必须有 EJU（日语300分＋综合科目100分＋总分400分）。不认 JLPT
- **神戸学院大学** — 必须有 EJU（日语240分）。不认 JLPT
- **上海大学** — 要求中国籍以外，你不符合
- **中日本自動車短期大学（岐阜）** — 短期大学（你指定排除）
- **大阪女学院大学** — 女子大学（你指定排除）
- **大阪キリスト教短期大学** — 短期大学（你指定排除）
- **城西国際大学** — 学校指定校名单上该校条件栏为空、日程未记载（标注「編集中」）＝当前不存在可执行的出愿路径。（大学官网2026定价138.7万可查，但指定校条件未发布前无法出愿）

### 前提

- 入学は全て **2027年4月**。表中の 2026年10〜12月 は出願・試験日であって入学月ではない。
- 出席率 100% のため、最も厳しい 95% 要件も含め全校クリア。この項目は候補を絞る条件にならない。
- N2 111点。数値指定があるのは 太成学院 112点（不足）と 京都外国語 100点（クリア）の 2 校のみ。
- **専願＝合格したら入学義務**。併願できないため、複数校への同時出願は原則不可。
- 日付・条件は元シートのセルから機械抽出したもの。**出願前に必ず募集要項の原本で照合すること。**
