    11/21 考场流程与礼仪

    大阪経済大学 口頭試問　11月21日（土）13:00（12:40までに入室）

    说慢一点，声音亮一点，看着老师的眼睛，嘴角带一点笑。老师听的是你的态度和亲和力，把对面老师聊舒服了就稳过。

    当天的流程

    出门前

    • 必带：A4竖向原寸打印的《受験票》（正反面绝对不能写任何字或做记号！）
    • 顺手带上：在留卡、学生证、交通卡／现金、手帕、纯走时手表（严禁戴智能手表／手环）
    • 西装外套只扣上面一颗，坐下也扣着；口袋清空，东西全放包里
    • 背双肩包的话，进校门前拿下来改成手提；折叠伞装进塑料袋塞包里

    到校与候考（11:40～12:40 入场，建议 12:00 到大隅校区）

    • 路线：大阪メトロ今里筋線「瑞光四丁目」站走 2 分钟（当天在校内揭示板看具体考场教室）
    • 12:40 前必须进候考室／考场入座，把 A4《受験票》 端正放在桌面考号牌正前方
    • 进教室前铁律：先把手机里的所有系统闹钟关掉，再彻底关机放进包里（防止关机闹钟自动响铃判违规）
    • 候考时坐直，微微笑，被叫到受验番号时清楚响亮地答「はい！」再起立

    进面试室

    1. 敲门 3 下，等里面说「どうぞ」再开门（如果门本来开着，在门口说「失礼いたします」鞠躬进去）
    2. 说「失礼いたします」，进去后转身面向门，双手轻轻把门关严
    3. 转向考官，礼貌鞠躬（30 度），走到椅子左边站好
    4. 报考号和名字（声音洪亮带笑）：「受験番号〇〇番、〇〇です。本日はどうぞよろしくお願いいたします。」说完深鞠躬（45 度）
    5. 考官说「どうぞ」后：说「失礼いたします」，轻轻点头坐下，包立放在椅子脚边
    6. 坐椅子前一半，背挺直不靠椅背，双脚与肩同宽，双手自然放在大腿上

    结束退场（考官说「これで終わります」）

    1. 先坐着微笑说：「本日はありがとうございました」，低头致意
    2. 起立站到椅子左边：「本日はお忙しい中、貴重なお時間をいただき、本当にありがとうございました」，深鞠躬（45 度）
    3. 拎起包走到门口，转身面向考官：「失礼いたします」，鞠躬后轻轻开门出去并把门带上
    4. 走出校门前都算面试中，不要掏手机，遇到老师或工作人员点头微笑致意

    困ったとき

    • 没听清再问一遍（微笑着说，不扣分）：「すみません、もう一度お願いできますでしょうか。」
    • 有某个词没听懂：「すみません、『〇〇』はどういう意味でしょうか。」（把听到的音照念一遍就行）
    • 想确认自己没理解错：「〇〇ということでしょうか。」等老师点头再答
    • 需要想两秒钟：「はい、少し考えてもよろしいでしょうか。」
    • 万一被问到完全没听过的冷门知识（千万别编，诚恳认下最讨喜）：「すみません、そこはまだ勉強不足でした。入学するまでにしっかり調べて勉強しておきます。」

    考官换个词问，其实还是上面同一道题

    • 志望動機・志望理由 → 第4题 どうして大阪経済大学
    • 入学後の抱負・意気込み → 第6题 大学で何を勉強したい
    • 将来の展望・卒業後の進路 → 第8题 卒業したら
    • 自己PR・強み・アピールポイント → 第11题 長所と短所
    • 学業とアルバイトの両立 → 第17题 アルバイト
    • 経費支弁者 → 第10题 学費（「両親です」）
