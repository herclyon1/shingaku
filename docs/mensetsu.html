    11/21 考场流程与礼仪

    大阪経済大学 国際共創学部 口頭試問 総台詞表（11月21日 13:00）

    说慢一点，声音大一点，看着考官老师的眼睛，嘴角带一点笑。整场15分钟考官拿着问题清单随机抽问，但你脑子里只装下面这6大块连贯台词表——问到哪一块，就切哪一块答。

    当天的流程

    出门前必查

    • 必带：受験票（A4白纸竖向原寸打印，正反面严禁写任何字！）、在留卡、学生证、黑笔、手表（无通信功能）、手帕、交通卡
    • 集合时间：11:40～12:40 入场，12:40 前必须进考场教室，13:00 正式开始（迟到超30分钟取消资格，务必 11:50 左右到大隅校区）
    • 手机进校门前先解除所有闹钟，彻底关机，连同钱包、钥匙一起放进包里，西装口袋全空
    • 西装外套只扣上面第一颗扣子（坐下也扣着）；双肩包进校门后改用手提

    进考场门（以当天引导老师指示为准）

    1. 敲门 3 下，听到「どうぞ」再推门（若门本来开着，在门口说「失礼いたします」鞠躬后进）
    2. 进去转身轻轻把门关好，再转向考官鞠躬（30 度）
    3. 走到椅子旁边站直，微笑响亮报号：「受験番号〇〇番、〇〇です。本日はよろしくお願いいたします。」说完深鞠躬（45 度）（注：语校名太长容易嘴瓢，考官手头有表，不用报；今天10点出受验番号后把号码念熟）
    4. 考官说「どうぞ」后：「失礼いたします」，点头坐下，包立放在脚边
    5. 坐椅子前一半，背挺直不靠椅背，双手轻握放在大腿上，全程面带温和微笑看着说话的老师

    结束退场（考官说「これで終わります」）

    1. 先坐着微笑说：「ありがとうございました」，点头
    2. 起身站到椅子旁：「本日はお忙しい中、お時間をいただき、ありがとうございました。」深鞠躬（45 度）
    3. 提包走到门口，转身面向考官：「失礼いたします」，鞠躬后轻手开门离开
    4. 走出校门前绝不掏手机

    困ったとき

    • 没听清：「すみません、もう一度お願いできますでしょうか。」
    • 某个词没听懂：「すみません、『〇〇』はどういう意味でしょうか。」（把听到的词照音念一遍，绝不硬猜乱答）
    • 想确认自己没理解错：「〇〇ということでしょうか。」等老师点头再答
    • 需要3秒钟组织语言：「少し考えてもよろしいでしょうか。」
    • 完全没准备到的冷门知识：「すみません、そこはまだ勉強不足でした。入学までにしっかり調べておきます。」

    考官换个说法问，也是切同一块台词：

    • 志望動機・志望理由を教えてください → §10 为什么选大经大 ＋ §13 国际共创学部
    • 入学後の抱負・意気込み・やりたいこと → §14 大学四年具体学什么
    • 将来の夢・卒業後の進路・キャリアプラン → §9 毕业后的工作目标
    • 自己PR・自分の強み・アピールポイント → §18 优缺点与自我PR（前半段长处）
    • 学業とアルバイトの両立・週何時間 → §4 打工与出勤平衡
    • 経費支弁者・学費は誰が払いますか → §17 学费父母支持与减免
    • 併願校はありますか・専願ですか → §11 他校对比与必入学
