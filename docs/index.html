怎么看这张表
  • 入学时期全部是 2027年4月。表里 2026年10〜12月 的日期是报名和考试日，不是入学月。
  • 出勤率 100%，连最严的 95% 要求也过，所以这一项筛不掉任何学校。
  • N2 111 分。写了具体分数线的只有两所：太成学院 112 分（差1分不够）、京都外国語 100 分（够）。
  • 专愿＝考上就必须去，不能同时报别的学校。所以这不是撒网，是押一注。
  • 金额是第一年的。「实付」＝定价减去你能拿到的减免；划掉的是定价。第二年起的金额多数会变（有的减免只有第一年，有的跟成绩挂钩）。
  • 只是大学名单。另外还有专门学校的指定校 32 所没做进来。
  • 学校名、学部学科名、以及报名期间/考试日那些引用原文保留日文——这些是你去官网和募集要項里搜索、核对时要用的原字符串。
  • 日期和条件是从原表机械抽取的，学费是官网公开值。报名前必须用募集要項原本核对一遍。
