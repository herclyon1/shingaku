当天礼仪

校長面接　9月28日（月）11:00　ひえいビル3階

说慢一点，声音大一点，看着校长，带一点笑。

当天的流程

出门前

  • 带上：通知邮件（截图存进手机）、在留卡、学生证、手帕、笔和小本子、伞（预报今天有雨）
  • 手机调成静音，放进包里；钱包、钥匙也放包里，西装口袋空着
  • 外套只扣上面一颗，坐下也扣着
  • 背的是双肩包的话，进楼后从肩上拿下来，用手提着
  • 下雨电车可能会慢，早一点出门；进楼前用手帕擦一下鞋和西装
  • 伞：长伞放进伞架，折叠伞装进塑料袋放包里。进房间时手里只拿包

受付（10:55 左右到 3 楼）

  • 给前台看面试通知邮件：「B園田1クラスのへ へリオンです。11時から校長面接があります。よろしくお願いします。」
  • 要等的话，坐直等，手机一直放在包里。叫到名字时清楚地答「はい」，站起来

进门

  1. 敲门 3 下，等里面说「どうぞ」（门开着就不用敲，在门口说「失礼いたします」，鞠躬后进去）
  2. 「失礼いたします」，开门进去
  3. 转身面向门，用手轻轻关上
  4. 转向校长，鞠躬（30 度）
  5. 走到椅子左边站好：「B園田1クラスのへ へリオンです。本日はよろしくお願いいたします。」说完再深鞠躬（45 度）
  6. 校长说「どうぞ」后：「失礼いたします」，轻轻点头，坐下
  7. 包放在椅子旁边的地上（立不住就靠着椅子腿）
  8. 坐椅子的前一半，背离开椅背，挺直，下巴稍微收一点。两脚分开，跟肩膀一样宽；手轻轻握拳，放在膝盖上

结束（校长说「これで終わります」之类的话）

  1. 先坐着说「ありがとうございました」，点一下头
  2. 站到椅子左边：「本日はお忙しい中、お時間をいただき、ありがとうございました」，深鞠躬（45 度）
  3. 拿包走到门口，转身面向校长：「失礼いたします」，鞠躬
  4. 侧着身开门，出去，轻轻关上门
  5. 出了房间到走出大楼，都还算面试：手机出了楼再看，碰到同学和老师，小声打个招呼就好

困ったとき

  • 听不清：「すみません、もう一度お願いします」
  • 有一个词不懂：「すみません、『〇〇』は、どういう意味でしょうか」。〇〇 就是把听到的音照着说一遍
  • 大概懂了但没把握：「〇〇ということでしょうか」，校长说「そうです」再答
  • 想一下：「少し考えてもいいですか」
  • 真的不知道：「すみません、勉強不足でした。入学までにしっかり調べます」

校长可能换个词问，意思跟上面的题一样

  • 志望動機・志望理由 → 第4题 どうして大阪経済大学
  • 入学後の抱負・意気込み → 第6题 大学で何を勉強したい
  • 将来の展望・卒業後の進路 → 第8题 卒業したら
  • 自己PR・強み → 第12题 長所
  • 弱み → 第12题 短所
  • 学業とアルバイトの両立 → 第20题 アルバイト
  • 経費支弁者 → 第10题 学費（「両親です」）
